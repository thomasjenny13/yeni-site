Outil local : rien n'est envoyé sur le réseau, tout se passe dans ce navigateur. Ouvre ce fichier directement (double-clic) ou via un petit serveur local.
Le contenu privé du site est chiffré en AES-GCM 256, clé dérivée du mot de passe familial (PBKDF2-SHA256).
Tous les fichiers d'un même site doivent partager le même sel : utilise « Nouveau lot » la première fois, puis « Lot existant » (en fournissant probe.enc) pour ajouter ou régénérer des fichiers.
